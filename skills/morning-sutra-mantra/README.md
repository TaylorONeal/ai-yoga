# Morning Sutra Mantra

A verse-led contemplative practice with grounded interpretation, an original mantra, and continuity across days. Read [SKILL.md](SKILL.md) for the full instructions and the two craft/continuity references for deeper methods.

Install the whole folder into your assistant's skills directory. Ask for “today's sutra contemplation.” On first use it can work without any personal profile or connected account. Optional scheduling is configured separately in your assistant.

The skill reads available, authorized context; it does not require calendar access. AI-provider data policies apply to information you share with the assistant. Save daily entries and verse history in a private user-selected folder outside the public repository and installed skill. Existing history and bans should survive upgrades.

MIT licensed. Ancient source texts and modern copyrighted editions are different: verify citation/transliteration and use an original English reading rather than copying modern translations wholesale.
