# Teaching dossier structure

Use for a requested full study document, not a one-line flow. Fill only what the evidence supports. Unknown metadata remains unknown; omit a phase that did not occur. Render the actual artifact and inspect every page when producing Word/PDF.

1. **Title and class identity:** a source-supported theme or plain title; teacher, venue, location/date only when known. Do not invent a poetic teacher quote.
2. **Class snapshot:** how the class moved, its breath/attention, main work and close. Keep observations separate from inference.
3. **At a glance:** type, level if known, props, actual duration, theme, peak or other emphasis, and section-specific uncertainty.
4. **Class arc:** phase, cumulative time range and segment duration. State scheduled versus actual practice length and whether timings are estimates.
5. **Simplified flow:** one line per phase using arrows and explicit side/repeat/option markers.
6. **Side logic:** list symmetric work once with R+L or first/second-side notation. Use a comparison only for genuine differences.
7. **Scaffolding:** trace the principal demand to earlier preparations; use hold/attention architecture for a quiet class rather than inventing a peak.
8. **Structural notes:** repetition, recurring cue, changes of pace, props, resets and optionality.
9. **Why it works:** a few concrete architectural observations; do not assert unverified medical mechanisms.
10. **Cue thread by phase:** short, actionable study cues. Mark newly written adaptations as such.
11. **Practice reminders:** precise transition, side, pacing, consent and prop details useful for study. No invented injury advice.
12. **Who it is for:** infer cautiously from observed demands and offered options, not imagined student demographics.
13. **Signature language / teaching feel:** verified brief quotations with traceability, or clearly labelled paraphrases. Never blur them.
14. **Pose-family tags:** searchable labels, preserving relevant style distinctions.
15. **Timing estimates:** include only if they add to the arc; maintain one consistent timing model.
16. **Dependency map:** preparation → demand → resolution, with uncertainty where a phase is missing.
17. **Recurring teacher patterns:** only with independent multi-class evidence; otherwise title it observations from this class.
18. **Longer teaching script:** a real start-to-finish speakable script that follows the reconstructed arc. Include optional paths and both-side logic. This is a study adaptation, not a transcript.
19. **Items to verify:** precise remaining questions plus a concise source/coverage note. Keep detailed processing logs separate from the reader-facing body without disguising the evidence basis.

After a correction, update flow, side logic, timeline, dependency map, script, tags and confidence together. A corrected pose in one table with stale instructions elsewhere is not a completed revision.

Visual direction: calm hierarchy, generous spacing, legible tables and a restrained palette appropriate to the user. Avoid clipping, tiny text, duplicated mirror tables and empty template sections. Do not add personal credits or private metadata to a shared document without a request.
